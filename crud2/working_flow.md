**Modification Workflow**

1. **Database**

   `_create_db.txt`

   Database ও Student Table পরিবর্তন।
2. **Connection**

   `db_connect.php`

   Database name পরিবর্তন।
3. **Create**

   `create_input.php` এবং `create_result.php`

   Form ও INSERT Query পরিবর্তন।
4. **Read**

   `read.php`

   SELECT Query এবং HTML Table পরিবর্তন।
5. **Update**

   `update_input.php` এবং `update_result.php`

   Existing Data ও UPDATE Query পরিবর্তন।
6. **Delete**

   `delete.php`

   Table ও ID অনুযায়ী DELETE Query পরিবর্তন।
